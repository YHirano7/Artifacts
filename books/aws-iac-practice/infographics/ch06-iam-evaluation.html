IAMは「明示的なDenyが最優先、Allowがなければ拒否」
1つのアカウントの中なら、上から順に3つの問いに答えるだけで結果が決まります
1
どこかに明示的な Deny があるかSCP・境界・ロール・リソース側のポリシーのどれか
ある
拒否Allow があっても覆らない
↓ ない
2
SCP と境界の「上限」の中に収まっているかOrganizations の SCP、アクセス許可の境界
外
拒否上限の外は許可できない
↓ 中
3
ロールかリソース側に Allow があるかアイデンティティベース／リソースベースのポリシー
ない
暗黙の拒否書かれていなければ拒否
↓ ある
✓
許可
アクセスできる必要な分だけ Allow する
ロールに付く2種類のポリシー
信頼ポリシー誰がこのロールを引き受けられるか
権限ポリシーこのロールで何ができるか
CDK なら対象を絞って生成
caSigningKey.grant(issuer,
  "kms:Sign", "kms:GetPublicKey");
table.grant(issuer, "dynamodb:PutItem");
信頼ポリシーは条件まで書く
"Principal": { "Service": "lambda.amazonaws.com" },
"Action": "sts:AssumeRole",
"Condition": { "StringEquals":
  { "aws:SourceAccount": "111122223333" } }
避けたい書き方：Action: "*"、Resource: "*"、渡し先を絞らない iam:PassRole
