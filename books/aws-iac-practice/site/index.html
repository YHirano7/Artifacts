この本について

AWS のリソースを、コンソールでの手作業ではなくコードで管理するための入門書です。CloudFormation と AWS CDK の基本を押さえたうえで、実務でよく出てくる三つの題材を最後まで作り切ります。

  • KMS：データ暗号化用の鍵と、署名専用の鍵をコードで管理する
  • mTLS：クライアント証明書を発行する Lambda と、証明書で認証する API を作る
  • Codeシリーズ：CodeCommit・CodeBuild・CodePipeline で、承認付きのデプロイを自動化する

想定している読者は、アプリケーション開発や運用の経験はあるものの、AWS はまだ初級から中級という方です。IAM やネットワークを完璧に理解している必要はありません。必要な知識はその都度説明します。

サンプルコードは TypeScript（CDK）と Go（Lambda）で書いています。すべてのサンプルは cdk synth とユニットテストで検証していますが、実際の AWS アカウントへのデプロイは読者の環境で行う前提です。料金やサービスの状況は変わるため、各章に確認日を記しています。

チャプター

  1. Chapter 01はじめに：この本で身につくこと対象読者、前提知識、この本の読み進め方とサンプルコードの使い方を説明します。
  2. Chapter 02IaCとは何か：手作業の何が問題なのかコンソール操作で起きる事故を出発点に、IaC が解決することと解決しないことを整理します。
  3. Chapter 03AWSのIaCツールを見渡すCloudFormation、CDK、SAM、Terraform の関係と、どれを選ぶかの判断軸をまとめます。
  4. Chapter 04CloudFormationの基本を押さえるテンプレート・スタック・変更セットの考え方を、S3 バケットのテンプレートで確かめます。
  5. Chapter 05AWS CDKでインフラをプログラミングするConstruct の階層、synth と deploy、ブートストラップ、テストの書き方を学びます。
  6. Chapter 06IAMをコードで設計する最小権限を IaC で表現する方法と、ポリシー評価のしくみ、よくある落とし穴を扱います。
  7. Chapter 07実践1：KMSの鍵をIaCで管理する対称キーと署名用の非対称キーを作り、キーポリシーで管理者と利用者を分けます。
  8. Chapter 08実践2：mTLS用クライアント証明書を発行するLambdaKMS を CA の鍵として使い、証明書を発行する Lambda と mTLS の API をまとめて構築します。
  9. Chapter 09実践3：CodeシリーズでIaCのデプロイを自動化するCodeCommit・CodeBuild・CodePipeline で、テスト・変更セット・承認を経てデプロイする流れを作ります。
  10. Chapter 10運用で困らないIaCの設計スタック分割、ドリフト、削除保護、シークレット管理、コストなど、運用で効く設計の勘所をまとめます。
  11. Chapter 11おわりに：次に学ぶことこの本の内容を振り返り、実務で次に取り組むテーマと学習リソースを紹介します。
