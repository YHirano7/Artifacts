## この章で分かること

- この本がどのように作られ、どう読むのか
- ソース（`src/`）とビルド結果（`site/`）の関係
- 読み進める前に必要なもの

## この本の成り立ち

この本は、Markdown で書いた章を `tools/build.py` で HTML に変換して作られています。出来上がった `site/` は、どこに置いてもそのまま読める静的ファイルの集まりです。

![本ができるまで：Markdown の章と画像を build.py がまとめて site/ に出力する](../images/ch01-book-structure.png)

図の左側が書き手が編集する部分、右側が読者に届く部分です。章の追加・修正は `src/` に対して行い、ビルドのたびに `site/` が作り直されます。

## 読み方

サイドバーかトップページの一覧から章を選びます。JavaScript が有効なら、ページの再読み込みなしで章を切り替えられます。無効でも、各ページのリンクで同じように読み進められます。

:::message
`file://` で直接開いた場合は、常に通常のリンク遷移になります。表示の崩れではありません。
:::

## まとめ

- この本は Markdown からビルドされた静的HTMLで、配布先を選ばない
- `src/` を編集し、`tools/build.py` で `site/` を作り直す
- JavaScript がなくても全ての章を読める

## 確認問題

1. 章を追加するとき、編集するのは `src/` と `site/` のどちらですか。
2. JavaScript を無効にした読者は、この本を読めますか。

:::details 解答
1. `src/` です。`site/` はビルドのたびに作り直されるため、直接編集すると消えます。
2. 読めます。目次や確認問題の解答は `details` 要素で開閉するため、JavaScript なしでも動作します。
:::
