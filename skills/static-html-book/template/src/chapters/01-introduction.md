## この章で分かること

- この本がどのように作られ、どう読むのか
- ソース（`src/`）とビルド結果（`site/`）の関係
- 読み進める前に必要なもの

## この本の成り立ち

この本は、Markdown で書いた章を `tools/build.py` で HTML に変換して作られています。出来上がった `site/` には、表紙と全章をまとめた `index.html` と、本文で使う画像を入れた `images/` だけが入ります。どこに置いても、そのまま読めます。

![本ができるまで：Markdown の章と画像を build.py がまとめて site/ に出力する](../images/ch01-book-structure.png)

図の左側が書き手が編集する部分、右側が読者に届く部分です。章の追加・修正は `src/` に対して行い、ビルドのたびに `site/` が作り直されます。

## 読み方

サイドバーか表紙のチャプター一覧から章を選びます。JavaScript が有効なら、章を1つずつ表示し、再読み込みなしで切り替えます。ブラウザの「戻る」で、前に読んでいた位置に戻れます。

JavaScript が無効なら、表紙のあとに全章が縦に並んだ1ページになります。サイドバーのリンクは、ページ内の各章へのジャンプとして動きます。

:::message
`file://` で直接開いても、Web サーバーで配信しても、動きは同じです。章の切り替えに通信を使わないためです。
:::

## まとめ

- この本は Markdown からビルドされた1枚の HTML と画像だけでできていて、配布先を選ばない
- `src/` を編集し、`tools/build.py` で `site/` を作り直す
- JavaScript があれば章ごとに切り替え、なければ全章を縦に並べて読める

## 確認問題

1. 章を追加するとき、編集するのは `src/` と `site/` のどちらですか。
2. JavaScript を無効にした読者は、この本を読めますか。

:::details 解答
1. `src/` です。`site/` はビルドのたびに作り直されるため、直接編集すると消えます。
2. 読めます。全章が1ページに縦に並び、目次や確認問題の解答は `details` 要素で開閉できます。
:::
