# ブラウザでの確認

ビルドした `site/` を、次の環境で操作して確かめる。HTTP で配信するときは、本のディレクトリで次を実行する。

```bash
cd site && python -m http.server 8000 --bind 127.0.0.1
```

## HTTP 配信 + JavaScript 有効

- [ ] サイドバーの章リンク・前後の章へのリンクで、ページを再読み込みせずに本文が切り替わる
- [ ] ブラウザの「戻る／進む」で、URL と本文が一致したまま切り替わる
- [ ] 右側の目次で、読んでいる位置の見出しがハイライトされる。読書進捗のバーが動く
- [ ] コードブロックの「コピー」でクリップボードにコピーされる
- [ ] ←／→キーで前後の章に移動する。入力欄にフォーカスがあるときは移動しない
- [ ] `chapters/xx.html#見出しID` を直接開くと、その見出しの位置に移動する。リロードしても同じ章が表示される
- [ ] 先頭の章の「前へ」と、末尾の章の「次へ」がトップページへのリンクになる

## 遷移が重なる操作

ネットワークを遅くした状態（DevTools のスロットリング、または応答を遅らせるプロキシ）でも試す。

- [ ] 章リンクを続けてクリックしても、最後にクリックした章が表示され、URL と本文が一致する
- [ ] ページ内の目次リンクでアンカー移動したあと別の章に進み、「戻る」で元の章とアンカー位置に戻る
- [ ] 章の読み込み中に「戻る」を押しても、あとから別の章に切り替わらない。読み込み中の表示（半透明）も消える
- [ ] アンカーと章の遷移が混ざった履歴を、何度か「戻る／進む」しても URL と本文が一致する

## file:// + JavaScript 有効

- [ ] `site/index.html` を直接開き、全章をリンクで行き来できる（fetch は使わず、通常のリンク遷移になる）
- [ ] すべての図が表示される。コンソールにエラーが出ない

## JavaScript 無効

- [ ] 全章に通常のリンクで移動できる。前後の章へのリンクも使える
- [ ] 「このチャプターの目次」と確認問題の解答が、`details` で開閉できる
- [ ] 375px 幅で、メニューボタンからチャプター一覧を開閉できる

## 375px 幅（モバイル）

- [ ] 1列のレイアウトになり、ページ全体が横にはみ出さない
- [ ] 長いコードはコードブロックの中だけで横スクロールする
- [ ] 表と図が読める大きさで表示される
- [ ] JavaScript 有効時、メニューから章を選ぶとメニューが閉じる

## single 形式（1つのHTML + images/）

`single/index.html` は `file://` で開いても動く。追加で次を確かめる。

- [ ] サイドバーの章リンクで `#ch-<slug>` に切り替わり、再読み込みなしで表示・タイトル・右上の章番号が変わる
- [ ] `#top`（表紙）では全幅の表紙ページが出て、章レイアウトとトップバーが隠れる
- [ ] `#s<章>-<番号>` のような見出しアンカーを直接開くと、その章のその見出しが表示される
- [ ] 「戻る／進む」で URL のハッシュと表示が一致したまま切り替わる。章リンクの連打でも最後に選んだ章が出る
- [ ] 章を表示中に ←／→キーで前後の章・表紙に移動する（表紙では何もしない）
- [ ] JavaScript 無効では、表紙のあとに全章が縦に並んで1ページとして読める
- [ ] 375px 幅で1列レイアウトになり横にはみ出さない。メニューから章を選ぶとメニューが閉じる

## 報告の形式

結果は「N件中X件PASS／Y件FAIL／Z件未検証」の件数と、「# | テストケース | 結果」の表で報告する。FAIL と未検証には、理由か対応を一言添える。
