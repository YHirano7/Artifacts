# ブラウザでの確認

## 自動確認（browser_check.py）

```bash
pip install playwright && python -m playwright install chromium   # 初回のみ
python tools/browser_check.py              # site/ を確かめる
python tools/browser_check.py --chrome /path/to/chrome   # 手元の Chrome を使う
```

`file://`・HTTP（内蔵の簡易サーバー）・JavaScript 無効・375px 幅・JS 失敗時の5つの環境で、下のチェックリストのうち「自動」の項目を操作して確かめる。結果は「N件中X件PASS／Y件FAIL」と表で出し、FAIL が1件でもあれば終了コード 1 になる。Playwright を入れられない環境では終了コード 2 で止まるので、下の手順を手で行う。

自動確認が通っても、見た目（崩れ・重なり・読みにくさ）は分からない。JavaScript 有効の表紙と章、JavaScript 無効の全体、375px 幅の章は、スクリーンショットを撮って自分の目で確かめる。

## 手動で確かめるとき

`site/index.html` をブラウザで直接開く（`file://`）。HTTP でも確かめるときは、次を実行して `http://127.0.0.1:8000/` を開く。

```bash
cd site && python -m http.server 8000 --bind 127.0.0.1
```

JavaScript を無効にするには、DevTools のコマンドメニューで「Disable JavaScript」を実行する。

## チェックリスト

### JavaScript 有効（file:// と HTTP の両方）

- [ ] （自動）開いた直後は表紙だけが表示され、トップバーと章は隠れている
- [ ] （自動）「本を読む」・サイドバー・前後の章のリンクで、再読み込みせずに1章だけが表示される
- [ ] （自動）ページタイトル、トップバーの章番号、サイドバーの現在位置が切り替わる
- [ ] （自動）「戻る」で前の章の読んでいた位置に戻る。「進む」も URL と表示が一致する
- [ ] （自動）章リンクを続けてクリックしても、最後にクリックした章が表示される
- [ ] （自動）`#s<章>-<番号>` を直接開くと、その章のその見出しが表示される。再読み込みしても同じ章が出る
- [ ] （自動）←／→キーで前後の章に移動する。1章目の←は表紙に戻る
- [ ] （自動）右の目次は表示中の章の分だけが出る。コードブロックに「コピー」ボタンがある
- [ ] （自動）すべての図が読み込める。コンソールにエラーが出ない
- [ ] 読んでいる位置の見出しが右の目次でハイライトされ、読書進捗のバーが動く
- [ ] 「コピー」でコードがクリップボードに入る

### JavaScript 無効

- [ ] （自動）表紙のあとに全章が縦に並ぶ
- [ ] （自動）各章の先頭に「このチャプターの目次」が出て、右の目次は出ない
- [ ] （自動）サイドバーのリンクで、その章の位置にジャンプする（見出しがトップバーに隠れない）
- [ ] （自動）確認問題の解答（`details`）が開閉できる

### 375px 幅（モバイル）

- [ ] （自動）1列のレイアウトになり、ページ全体が横にはみ出さない
- [ ] （自動）JS 有効：メニューボタンでチャプター一覧が左から開き、章を選ぶか Esc で閉じる
- [ ] （自動）JS 無効：メニューボタンで表紙のチャプター一覧にジャンプする
- [ ] 長いコードはコードブロックの中だけで横スクロールする
- [ ] 表と図が読める大きさで表示される

### JS 失敗時

- [ ] （自動）JavaScript の途中で例外が起きても、全章を縦に並べた表示に戻って読める

### 印刷

- [ ] 印刷プレビューで、表紙と全章が出る。サイドバー・目次・ページ送りは出ない

## 報告の形式

結果は「N件中X件PASS／Y件FAIL／Z件未検証」の件数と、「# | テストケース | 結果」の表で報告する。FAIL と未検証には、理由か対応を一言添える。
