# プレゼンのストーリー設計

スライドを書き始める前に、話の骨格を決める。本文作成は骨格を本人が承認してから。

## まず4項目を決める

1. **目的**: このデッキで得たい結果（承認・合意・理解など）
2. **聴衆**: 誰に読ませるか・誰が決めるか
3. **欲しい行動**: 読後に相手が取る具体的な動作を動詞で
4. **キーメッセージ**: デッキ全体の主張を1文で

## スライド構成の起案

以下の受入基準を満たす構成を作る:

- 各コンテンツスライドの主張は「〜する」「〜である」と言い切る1文（アクションタイトル）。テーマ名の羅列は禁止
- 主張文を上から順に読むだけで話が通る（結論→根拠→手順→対処）
- 聴衆が反論しそうな点への回答をスライドに含める
- 枚数は指定がなければ10〜20枚
- まとめページは「承認してほしい事項」など、欲しい行動に直結させる

構成案を見せて承認を得てから、各スライドの本文に進む。承認なしに本文を作り込まない。

## 各スライドに書くもの

- 主張1文（タイトル）
- 本文（箇条書き・表・図解の中身）
- 話し手メモ1〜3文（口で補う説明。想定値には「想定値」と明記）
